# Gospel Streamers

A worldwide Christian social platform prototype inspired by TikTok and Instagram.

## Current package

The starter project includes a Next.js web app and an Android WebView wrapper. The Android wrapper needs the web app deployed to an HTTPS address before it can load. This repository README confirms the GitHub connection and documents the project direction.

## Build status

This is a prototype starter, not a production-ready social network. Authentication, database hosting, media storage, push notifications, deployment, and Android release signing still need configuration and testing.
